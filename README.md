# Brisca Maldita

Roguelike de cartas con la baraja española de 40 cartas: manos de póker, fichas de brisca, palo de triunfo, cantes de veinte y de las cuarenta, bufones, estampitas que suben de nivel las manos y jefes con reglas propias. Son 8 apuestas de tres ciegos, y al ganar se puede seguir sin fin.

Sitio: https://adrianezd.github.io/brisca-maldita/

- `datos.js`: palos, manos, bufones, jefes y objetivos. Para añadir un bufón basta con añadirlo a `BUFONES`.
- `script.js`: partida, evaluación de manos, tienda y pintado.
